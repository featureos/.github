# FeatureOS

[FeatureOS](https://featureos.com) is a product feedback, roadmap, changelog and help center platform. Collect feature requests, prioritize with votes, share a public roadmap, and announce what shipped, all in one place. Built by [Skcript](https://skcript.com).

[Website](https://featureos.com) · [Pricing](https://featureos.com/pricing) · [Changelog](https://featureos.com/changelog) · [MCP server](https://github.com/featureos/featureos-mcp)

## What you can do with FeatureOS

- **Feedback boards**: capture, vote on and merge feature requests.
- **Public roadmap**: show customers what is planned, in progress and shipped.
- **Changelog**: publish release notes and keep users in the loop.
- **Help center**: write and organize self-serve articles.
- **AI and MCP**: manage all of the above from Claude, Cursor and other MCP clients.

## Open source

| Repository | What it is |
|---|---|
| [featureos-mcp](https://github.com/featureos/featureos-mcp) | Official hosted MCP server. Triage feedback, publish changelogs and edit articles from Claude, Cursor, Gemini CLI or any MCP client. Endpoint: `https://mcp.featureos.app/mcp` |
